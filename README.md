# 言值输入法

言值，一句话的价值。

一个会帮你聊天的中文输入法。复制对方消息，点「言值AI」，三条不同风格的回复任你选——自然、温柔、幽默，点一下直接上屏。它不替你表白，不替你道歉，只帮你在想说又不知道怎么说的时候，把话说好。

## 它能做什么

- **AI 回复**：微信里长按对方消息复制，键盘上点「言值AI」→「AI 生成」，秒出三条风格迥异的回复，点「使用」上屏
- **挽回**：聊天冷了，给你一条能发出去的重新联系消息，不说教、不道歉、不查岗
- **自动规划**：接下来三轮怎么聊、隔多久回、她不回怎么办，一张对话树排清楚
- **顾问**：把她的消息丢给它，告诉你这句话什么意思、你该怎么接

云端配置：长按 AI 面板标题，填入任意 OpenAI 兼容接口（智谱 / DeepSeek / Kimi / 中转站皆可）。不配置也能用，内置策略引擎离线兜底。

## 输入法本体

完整继承语燕输入法的全部能力：

- 全拼 / 双拼（小鹤、自然码等 17 种）/ 笔画 / T9 / 手写 / 语音
- 英文、数字、符号、Emoji、颜文字
- 深色模式、主题、悬浮键盘、单手模式、键盘高度调节
- 词库扩展、剪贴板、常用语
- 无广告、无推送、不收集任何数据

## 安装

从 Releases 下载最新 APK 安装（允许未知来源），打开「言值输入法」→ 去系统设置启用 → 任意输入框切换即可。

## 隐私

剪贴板只在键盘处于前台时读取，用于生成回复；聊天记录仅存本机；云端 Key 只存手机，配置后消息内容将发送至你自己填的服务商。
